| 钓鱼 | 未验收 | 装备、抛竿、咬钩、收线、收获、消耗饵的完整流程 |
| 库存与交易 | 未验收 | 拾取、切换、丢弃、买卖及货币变化 |
| 世界与进度 | 未验收 | NPC 交互、任务交付、奖励、岛屿与 Boss 进度 |
| 船与战斗 | 未验收 | 船驾驶/升级、武器攻击、伤害、死亡与恢复 |
