# 水面、玻璃和旗帜的实质恢复

本轮从原版安装包中的 Shader 序列化状态和 DXBC 反汇编恢复局部算法。开发者原始 Shader Graph 未随游戏发布，完整光照/阴影/反射仍未证明等价。

## 原版证据

- WaterShader 嵌入 `globalgamemanagers.assets`，此前 original-shaders/inventory.json 没扫描该文件。已提取 84 个 DXBC 程序到 watershader-evidence。
- GlassShader 位于 `sharedassets0.assets` pathID 487；已提取 148 个 DXBC 程序到 glassshader-evidence。
- FlagShader 位于 `sharedassets4.assets` pathID 69；已提取 84 个 DXBC 程序到 flagshader-evidence。

复核方法：`Tools/Inspect-CharacterShader.py` 现支持第二参数指定 shader 名，第三参数指定安装包内 assets 文件名；输出目录按 shader 名区分。`Print-ShaderParams.py` 根据序列化的 NameIndices / ConstantBuffers 列出 UnityPerMaterial 寄存器对应属性，避免从名称猜逻辑。Windows 的 D3DDisassemble 仅用于分析原版编译程序，不是导出开发者原始源码。

## 已补回行为

Water 顶点程序 program-0 使用未变形的世界位置计算两组波相位；Testing 选择引擎时间或 FakeTime，加 WaveOffset，再使用各自 Frequency、GradientSpeed、Direction。顶点在对象空间执行 sin(phase)*Height 垂直位移和 cos(phase)*Height*Peak*原始方向的水平位移，最后转换到世界空间，因此保留模型尺度。现已恢复 Peak 的水平位移和 FakeTime 行为；上一版只有世界空间竖直 sin 波，且可能第二组波使用已变形的位置。fragment program-10 中的 3 层 Tchou value-noise（权重 .125/.25/.5）、Pixels UV 量化、深浅双色插值、场景深度和 depth-strength 控制以及 Tchou 梯度噪声岸边泡沫也已恢复。原版 opaque render type 保留。原版的法线纹理、SSS、完整反射及高光不在这一局部恢复中；旧版近似法线光照和距离雾仍保留。

Glass 的原版 forward pass 绑定 Src/Dst Blend、ZWrite、ZTest、Cull 到材质属性，材质 Glass2 使用 SrcAlpha/OneMinusSrcAlpha 且不写深度。现恢复 Transparent 队列和这些绑定，避免玻璃被实心绘制。program-100 的透明度为 `saturate(min(max(smoothstep(SmoothStep,1-abs(N dot V)) + distanceRamp,UV3.y),AlphaMax))`，distanceRamp 来自 DistanceMinMax；法线纹理使用 UV1、NormalScale，NormalStrength 随距离渐弱。这些行为已恢复，光照仍近似。

Flag 的 vertex program-0 符合本地官方 ShaderGraph GradientNoiseNode + Core Hash_Tchou_2_1 算法：以 `(positionOS.xy + time * WindSpeed.xy) * NoiseScale` 采样梯度噪声，映射到 -1..1，乘 WindStrength 和 positionOS.z 的平方，然后 `signedDisplacement*WindAxis + abs(displacement)*WindAxis2` 叠加到对象位置。现据此恢复旗帜摆动。WindNoiseAxis 没有在该原版顶点程序中使用，不额外推测用途。

本轮未启动 Unity。编译、运行和实际画面对照由主任务在独立验证副本执行；仍需检查深度纹理可用性和全部参数响应。
