# 完整恢复进度与原版一致性

## 已完成的可验证部分

1. 将游戏安装包 Managed 目录的全部 178 个 DLL 反编译成 17,555 个 C# 文件。游戏代码 363 个，第三方库代码 1,852 个，Unity 托管代码 7,345 个，.NET/Mono 库代码 7,995 个。各项均有原始 SHA-256、退出码和错误标记检查；178 项均正常退出且没有匹配到已检查的错误标记。这不等于重新编译或语义等价验证。
2. 原始游戏的 346 个文件全部保存到 original-artifacts，总字节数 680,800,047；逐文件 SHA-256 校验一致。完整原始资源、编译后 shader、原生引擎及插件均在该副本中保留，没有用替代文件覆盖原版数据。
3. 将此前恢复工程中遗漏的 lib_burst_generated.dll、libonigwrap.dll、meta_voice_chat_neteq.dll、rnnoise.dll、steam_api64.dll 补入 Assets/Plugins/x86_64，逐文件 SHA-256 与原版一致。插件导入和运行行为仍需要 Unity 编辑器验证。
4. 人物审计从三个玩家预制体扩展到全部 182 个预制体、12 个场景的序列化资源引用，覆盖 2,222 个可达文件。已检查 439 个蒙皮渲染器、1,560 个网格渲染器、4 个 Animator、15 个 Animation，以及 33 个皮肤相关配置实例（含 18 个 Clothes）。未发现缺失的 GUID、本地 fileID 或可解析 YAML 外部 fileID。8,267 条依赖导入器生成的 fileID 引用尚未在 Unity 中验证；动态按字符串加载及运行行为也不属于该静态结论。详细结果见 人物资源核对.md 与 all-character-resource-audit.json。
5. C# 项目引用改为相对指向 original-artifacts 的原始托管库副本，不再依赖 D 盘 Steam 安装目录。
6. 核对全部生成项目中的 569 个 HintPath 文件引用，均指向存在的文件；源码压缩包含 17,555 个 C# 和 178 个 csproj。这是文件存在性和打包检查，不是编译验证。
7. 换装核对覆盖两套 SkinManager、18 个 Clothes（4 个基础服装和 14 个 NPC 服装）以及全部导出蒙皮引用。关联清单包含 167 个网格、11 个材质、2 个贴图、4 个替代 shader，包含动物/物品，不能当成人物数量。详细资产列表保存在 character-wardrobe-inventory.json。

## 输出

- recovered-code：全部可导出的托管 C#，按程序集分目录。
- HowToFish-CSharp-complete.zip：仅包含上述 C# 和生成的项目文件；csproj 的依赖在 original-artifacts 中，压缩包单独拿走不构成可编译工程。
- recovered-unity-project/ExportedProject：资源恢复工程。
- original-artifacts：与原版逐文件一致的安装包副本，供比对和保留无法逆向恢复的原始数据。

## 尚未满足“与原本的一样”的部分

- 人物 CharacterShader 有 DummyShaderTextExporter 标记，fragment 恒返回白色；这不能视为原版着色器源码。原版编译后 shader 保存在 original-artifacts 中，但不能自动还原为开发者原始 HLSL/Shader Graph。
- Unity 编辑器 6000.4.4f1 尚未安装；此前官方国际与中国节点均返回 404。Unity Hub 已安装。恢复工程尚未在对应编辑器中导入、编译、运行。
- 原始编辑器工程、完整第三方包配置、编辑器工具、开发者注释和未随游戏发布的源码不能从这个安装包证明或完整恢复。
- Unity 引擎原生代码及原生插件实现不是 C#。导出的 Unity C# 中保留的 extern/内部调用只能表示接口，不能算作原生实现的恢复。
- 原版的运行截图和人物动画尚未与恢复工程逐帧比对，物理、联机、语音、音频和存档兼容性也未完成运行验证。

当前已完成安装包内全部托管代码的导出和全部导出场景/预制体的静态资源引用核对，但不能承诺恢复工程已经与原版等价。下一阶段需要取得可用的对应编辑器、激活个人 Unity 许可证，再逐项修复工程并与原版进行行为和视觉验证。不能为宣称完成而用近似 shader 或猜测的配置替换原版逻辑。
