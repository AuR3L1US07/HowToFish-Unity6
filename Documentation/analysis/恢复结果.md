查看场景或尝试运行：安装 Unity Hub 和 Unity 6000.4.4f1，添加上述 ExportedProject 目录。首次导入后，逐项修复编译、资源和渲染依赖问题；目前尚未在 Unity 中验证导入、编译或运行。

已安装的资源浏览服务地址：http://127.0.0.1:58321/ 。它只在当前电脑提供访问，并保留本次载入的资源。关闭服务后可启动 tools/AssetRipper/2.0.0/AssetRipper.GUI.Free.exe 再打开游戏文件夹。

导入时对 globalgamemanagers 中 asset type 129 报告 Read 920 but expected 924（Unity 6000.4.4f1）。资源导出仍完成，但该管理器数据不能视为完整恢复。

ILSpy 导出没有报告错误，且扫描未发现常见反编译错误标记；这不等同于代码语义、可编译性或运行行为已经验证。当前尚未安装 Unity，也没有 .NET SDK。
