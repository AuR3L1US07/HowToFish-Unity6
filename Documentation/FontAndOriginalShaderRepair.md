# 字体和原版着色器修复

动态字体图集已重新生成，并关闭退出编辑器时自动清空动态字形的选项。23 个字体保持原有字体资源引用。实际创建房间输入框已验证 `Local123` 可见；独立检测记录在 `CompilationChecks/latin-input-validation.txt`。

`Assets/StreamingAssets/Recovery/original-shaders.bundle` 包含从原版程序提取的 100 个编译后着色器，以及原版海水网格、贴图和材质。运行时为场景中的渲染器和 UI 创建材质副本并绑定同名原版着色器，不把资源包引用写回工程材质。海水控制器直接驱动恢复的运行时海水材质。该文件恢复的是运行程序，未恢复开发者的 Shader Graph 源图。

原版 PlayerSettings 中的色彩空间为 Linear，版本为 1.1.3；工程已采用对应设置。原版着色器和本地运行已分别在 Direct3D 11 与 Direct3D 12 中验证。

本地生成玩家、移动、存档读回及停止运行的检查已记录通过，错误列表为空。实际界面中中文、英文、数字和透明菜单背景已检查。整个游戏的视觉一致性尚未成立：海面纹理尺度仍与参考截图有差异，部分 VFX 仍为功能性重建。独立程序需要在最终修改后重新打包验证，已有旧构建不代表这次修复后的结果。

运行时更新脚本会重新加载管理对象。修改脚本前应停止 Play；多个本地游戏验证进程还会争用同一端口，验证时只启动一个进程。
